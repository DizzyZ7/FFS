# FFS — FrameForge Studio

Local-first video reference analysis and editing studio.

## Architecture
- Python / FastAPI backend
- Browser-based editor
- FFmpeg/ffprobe for local media processing
- Pluggable AI providers (planned)

## Development

The initial working prototype is available as `frameforge-studio-v0.1.zip` in the project conversation. Source migration into this repository is in progress.

### Roadmap
1. Reference upload and scene analysis
2. Timeline, preview, local MP4 export
3. Project persistence and audio
4. Optional AI video generation and motion transfer

No paid AI service is required for basic editing.
