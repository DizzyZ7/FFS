# Security Policy

## Supported versions

The project is pre-1.0. Only the current main branch receives security fixes.

## Reporting

Please do not publish a working exploit or sensitive logs in a public issue. Contact the repository owner privately through their GitHub profile or use GitHub private vulnerability reporting if enabled.

## Deployment warning

FFS is a local-first prototype. Run the API on `127.0.0.1`, not a public interface. There is currently no authentication, tenant isolation or secure public hosting configuration.

Do not upload secrets or private media to third-party generation services without explicit consent.
